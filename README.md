# Ephie Chat — Version 1

Mobile-first frontend prototype for:

**EPHIE CHAT**
Connect • Share • Discover • Opportunities
Founded by Ephraim M'bisa

## Included
- Mobile-first home/feed
- Post composer
- Photo/video/anonymous post entry points
- Chats screen
- Jobs/vacancies screen
- Create screen
- Profile screen
- Responsive desktop layout
- Demo interactions and navigation

## Important
This version is a frontend prototype. Real accounts, database storage, real-time chat, photo/video storage, push notifications and voice/video calls require a backend and third-party services.

## Run
Open `index.html` in a browser, or deploy the folder to Netlify/Vercel/GitHub Pages.
